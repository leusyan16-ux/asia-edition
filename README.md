# ASIA EDITION — технічний огляд вихідного коду

Незалежна платформа туристичних активностей Південно-Східної Азії. Цей репозиторій підготовлений для приватної технічної оцінки; він не містить робочих баз, клієнтських заявок чи доступів до хмарних сервісів.

## Стек та архітектура

- Next.js 16.4.3 App Router, React 19.3, TypeScript 5.9, Tailwind CSS 4.
- Node.js **24.x**, pnpm **10.34.8** — версії зафіксовані в `package.json` та lockfile.
- `src/app/[locale]` — RU/EN, головна, країни, каталог, деталі активностей, акаунт і кошик. RU — типова мова.
- `src/features/tours` — спільна модель, пошук/фільтри/сортування/пагінація, адаптери даних і статичний інформаційний знімок.
- `src/features/admin` — керування інвентарем, перевірки, галереї та імпорт CSV/JSON.
- `src/features/ingestion` — PostgreSQL/PGlite, імпортні завдання, checkpoint/resume, lease/fencing, проєкції та локальні медіа.
- `src/features/commerce` — Supabase Auth, кошик, вподобані, заявки, приватні PDF, Telegram outbox, CRM, ролі/MFA та аналітика за згодою.
- `src/app/admin` — захищені інтерфейси інвентарю й управління; серверні API перевіряють дозволи.
- `supabase/` — міграції 001–010, допоміжні SQL та перевірки. **Не запускати їх автоматично**: інвентар і commerce мають окремі залежності й інструкції.
- `tests/` — доменні, UI-rendering, імпортні та локальні SQL/RLS тести. PGlite не є перевіркою реального production PostgreSQL.

## Реалізовані можливості та дані

Каталог обмежений 11 країнами UN M49 Southeast Asia; маршрути на території РФ відсікаються. Статичний знімок містить 2319 інформаційних записів постачальника, з яких дві картки приховані окремим редакційним списком: поточний показ — **2317**. Це не 2317 перевірених пропозицій із гарантованими цінами чи наявністю. Ціни/орієнтири, які є в коді, не слід трактувати як актуальну оферту; частина орієнтирів доступна лише в staging.

Підготовлено акаунти, гостьовий/серверний кошик і вподобані, заявки з оформленням через менеджера, PDF-квитанції, сповіщення Telegram та CRM. Онлайн-оплата й автоматичне підтвердження постачальником не підключені. Klook feed/API не інтегровано: є адаптерний інтерфейс та офлайн-обробка наданих HTML/JSON/HAR, без обходу захисту.

Старі звіти в `docs/` описують стан на дату їх написання й можуть містити історичні показники. Вони не є доказом працездатності всіх зовнішніх інтеграцій зараз.

## Безпечний локальний запуск

```powershell
npx --yes pnpm@10.34.8 install --frozen-lockfile
Copy-Item .env.example .env.local
npx --yes pnpm@10.34.8 dev
```

Відкрити `http://localhost:3000/ru/tours` або `/en/tours`. Приклад середовища вмикає тільки статичний каталог. Supabase, commerce, адмінпанель і відправлення заявок вимкнено. Не копіюйте робочі ключі в репозиторій.

Для локальної адмінпанелі: створити власний локальний доступ через `pnpm admin:setup`, потім у **локальному** `.env.local` встановити `ADMIN_MODE=local`, `TOUR_DATA_SOURCE=local`, `PUBLIC_PREVIEW_ONLY=false` і перезапустити dev-сервер на localhost. Дані будуть в ігнорованій `.admin-local/`. Статичний знімок і локальна адмінська база — різні адаптери; перемикання не переносить дані автоматично.

## Перевірки

```powershell
npx --yes pnpm@10.34.8 exec next typegen
npx --yes pnpm@10.34.8 typecheck
npx --yes pnpm@10.34.8 lint
npx --yes pnpm@10.34.8 test
npx --yes pnpm@10.34.8 build
npx --yes pnpm@10.34.8 start
```

Для чистого checkout типи Next.js потрібно спочатку згенерувати (`next typegen`, `dev` або `build`). Частина тестів створює тимчасові синтетичні дані; їх не слід показувати як реальний каталог. Перевірені невиробничі набори у `data/pilots/` збережені для відтворюваності тестів; приватні імпорти та браузерні збереження не передаються.

Під час підготовки 17.11.2026 у чистій копії вихідного коду пройдено 140/140 автоматизованих тестів, генерацію типів, TypeScript та ESLint; це локальні перевірки, не production-сертифікація. Результати перевірки підготовки до передачі див. у [SOURCE_HANDOFF.md](docs/SOURCE_HANDOFF.md).

## Обмеження для оцінювача

- Під час підготовки 17.11.2026 підтверджено advisory для зафіксованого Next.js 16.4.3: [GHSA-mfr8-8qww-v76h](https://github.com/advisories/GHSA-mfr8-8qww-v76h), виправлена версія — 16.4.5. Перша чиста збірка після компіляції зупинилась на security-попередженні; повторна webpack-збірка пройшла, але залежності в межах передачі не оновлювалися й advisory залишається. Це відоме обмеження, а не доказ експлуатації сайту.

- Зовнішні Auth/email, Owner/MFA, Telegram, Storage та база потребують окремо наданого середовища. Відсутність ключів у цьому репозиторії є навмисною.
- Локальні JSON/PGlite — режими розробки; бенчмарки на синтетичних даних не доводять production-продуктивність.
- Аналітика поведінки працює за згодою. Dashboard оновлюється кожні 30 секунд в активній вкладці; вибраний період графіка зберігається. 90-денні заявки доступні за наявними записами, а давні відвідування поза строком зберігання позначаються невідомими, не нулями.
- Робочі клієнтські записи, 26 карток у локальному профілі, браузерні HAR/HTML, експорти, архіви, секрети та прив'язка Vercel не включені в Git. Окремий початковий редакційний набір із 26 фактологічних карток у `data/pilots/` є тестовим ресурсом для шаблонів, не копією робочої бази.
- Ліцензії фотографій/шрифтів і походження матеріалів описані в `docs/ASSET-SOURCES.md` та `public/fonts/OFL.txt`. Передача коду для оцінки не встановлює нових прав на сторонні матеріали.
