Партнерство й право продавати послуги не заявляються.

## Файли

- `products.json` — основний нормалізований імпорт, `schema_version=1`.
- `products.csv` — еквівалентний імпорт UTF-8 BOM/RFC 4180, з JSON місць у `locations_json`.
- `sources.json` — повний реєстр: офіційні URL, дата перевірки, підтверджені факти, межі підтвердження, права на тексти/зображення, зв’язок із попереднім кандидатом.
- `sources.csv` — читабельний скорочений реєстр. **Не завантажувати його як продукти.**
- `validation-report.json` — результати ізольованої симуляції через справжній імпортер.

`provider=asia_edition_editorial`. ID `AE-EDITORIAL-XX-01/02` належать нашому пілоту; це **не ID постачальника Klook**. Номери попередніх кандидатів існують тільки в дослідницькому реєстрі. Стабільний provider/ID запобігає дублям при повторному імпорті. Не змінюйте їх для оновлення тієї самої картки.

`import_status=needs_review`; імпортер завжди створює `draft`, `verifiedAt=null`. Поле `status` у файлі продуктів відсутнє за контрактом імпортера; статус чернетки перевірено на результаті симуляції. `last_synced_at=2026-10-14T00:00:00Z` позначає датований редакційний знімок з точністю до дня, **не синхронізацію з API або актуальність комерційної пропозиції**. `test_data=false`: факти про реальні об’єкти, не синтетичні екскурсії. Ізоляцію забезпечує профіль, а не змішування з demo.

## Межі даних і прав

Загальнодоступна сторінка не є ліцензією на її текст чи медіа. Фотографій немає; права на чужі фотографії не встановлено. Торговельні назви позначають об’єкти, не партнерство.

Тривалість — `null`; маршрути, включення, виключення, FAQ, пакети, ціни, розклад і доступність — порожні. Трансфери до об’єктів, точки зустрічі, умови скасування й бронювання не заявлено. Порожня ціна не означає безкоштовність. UTC у нормалізованому результаті — технічний default моделі без розкладу, не перевірений локальний часовий пояс.

Довгі комерційні маршрути свідомо звужено: VN-02 — Золотий міст, TR-02 — Дерінкую замість неперевіреної Green Tour, LK-01/02 — Сігірія та Дамбулла окремо, IN-01 — Тадж-Махал без інших зупинок, ID-02 — транспортна довідка без лаунжу, PH-02 — острів Пескадор без морського пакета. Дананг означає прив’язку комплексу до міста/його району, не центр міста. ## Окремий профіль і перевірка

Профіль — `.admin-local/pilot-editorial-26`. Після погодженого етапу 5 він містить `tours.json` з 26 чернетками, копії `sources.json`/`sources.csv`, `import-report.json` та `admin-verification-report.json`. До імпорту екскурсій не було; резервна копія порожнього сховища не потрібна. Постійних облікових даних немає: тимчасовий QA-вхід використано лише для перевірки та прибрано. Підготовлені матеріали зберігаються також у цій теці, щоб бути доступними в репозиторії. `.env.local` не змінено.

Для локальної сесії відкрийте PowerShell у корені проєкту:

```powershell
$env:ADMIN_MODE='local'
$env:TOUR_DATA_SOURCE='local'
$env:ADMIN_LOCAL_DIRECTORY='.admin-local/pilot-editorial-26'
pnpm admin:setup
pnpm dev --hostname 127.0.0.1
```

`admin:setup` потрібен один раз: задайте власний email і пароль; команда не перезаписує наявний обліковий запис. Відкрийте http://127.0.0.1:3000/admin та увійдіть. Каталог http://127.0.0.1:3000/ru/tours не показуватиме чернетки; приватне прев’ю доступне з редактора. Змінні діють тільки в цьому терміналі та мають пріоритет над `.env.local`. Для повернення до основного профілю приберіть `ADMIN_LOCAL_DIRECTORY` і перезапустіть сервер. Міграції Supabase не потрібні.

Безпечна повторна перевірка, яка створює й видаляє лише власне тимчасове сховище ОС:

```sh
node --import tsx scripts/validate-editorial-pilot.ts
node --import tsx --test tests/editorial-pilot.test.ts
```

Перша симуляція — 26 створених чернеток; повтор JSON та повтор CSV — по 26 пропущених, 0 нових, 0 оновлених, 0 помилок; 0 опублікованих. Порівнюються fingerprints CSV/JSON, збереження редакційної назви, незмінність внутрішніх ID, захист від повтору ID усередині файла, відсутність комерційних і медіаданих. Тимчасове сховище очищається через `finally` з перевіркою шляху. Це технічна валідація, не завантаження асортименту.

Етап 5 завершено: 26 редакторів і 52 локалізовані прев’ю перевірено через localhost; 52 публічні сторінки чернеток повернули 404. Наступний крок — редакційна перевірка масштабу кожної картки. Публікація й підключення постачальника — окремі завдання; поточні картки не є готовими до продажу.
