# Малий тест відкритих сторінок Klook — 25.10.2026

12 справжніх product IDs, усі Сінгапур. Це **ізольовані кандидати-чернетки**, не опубліковані комерційні пропозиції й не синтетика. Покриття інших шести країн цим тестом не підтверджено.

## Що фактично виконано

- Звичайний HTTPS GET `robots.txt`: 200. Загальна група `User-Agent: *` не забороняла activity/destination; заборонені search/searchresult, службові шляхи й окремі API. Це технічна директива, не додаткова ліцензія.
- Звичайний GET https://www.klook.com/en-US/activity/127-gardens-by-the-bay-singapore/: **403**, 777 символів, title=klook.com, JSON-LD не отримано. Прямий автоматизований збір зупинено на першій відмові; жодних проксі, ротації IP/User-Agent, CAPTCHA-solving, cookies/session impersonation або прихованих API.
- Через звичайний вебпошук/індексований читач доступні destination listing та 12 окремих сторінок. Це не успішний живий crawler: вік знімків різний, від today до last month. Дати на сторінках можуть бути минулими. Час `observed_at` — час нашого дослідження, не гарантія часу оновлення Klook; `last_synced_at` у кандидатах означає підготовку локального знімка.
- Доступні EN title, product ID/URL, місто, категорії, пакети, тексти описів, адреси, деякі suggested duration, відображені ціни та URL зображень. JSON-LD/embedded app state сирого HTML не досліджено через 403; не вигадуємо їхню структуру.
- Назви RU перекладено, короткі RU/EN описи написані заново на основі підтвердженої назви/географії. Довгі тексти, відгуки й рейтинги не копіювалися.
- Окремо збережено 12 видимих USD-цін зі списку, **не** adult/child pricing. Список і деталі можуть давати різні значення: наприклад, у Gardens by the Bay є різні пакети, включно з окремими додатковими послугами. Без package/person/date/validity mapping ці значення не можна переносити в ціну дорослого. У `products.json` prices/availability/packages порожні.
- Suggested duration часто є діапазоном; не перетворювали 3–5 годин на вигадану фіксовану тривалість. Діапазони збережені лише в observations; durationMinutes=null.
- Три thumbnail URL для продуктів 127/117/119 взяті зі списку. Звичайні HEAD повернули 200, image/jpeg, розміри 66395/50593/46063 байти. Бінарні файли не завантажені, візуальна відповідність не перевірена. Перше посилання Image на detail сторінці виявилося PartnerAward badge — воно виключене. HEAD 200 не підтверджує ні зміст, ні обсяг дозволу щодо конкретної фотографії.

## Файли й перевірка

- `observations.json`: реєстр 12 назв, URL-slugs/IDs, незалежні оригінальні короткі описи, спостережені ціни/діапазони й результати HTTP; це sidecar, не імпортний файл.
- `products.json`: чинний `schema_version:1/products:ExternalImportRecord[]` для наявного CSV/JSON імпортера.
- `validation-report.json`: create=12, failed=0; повторний запуск планувальника skip=12; усі draft, editorial=pending, rights=unknown, readiness=blocked, ready_for_publication=0.
- `scripts/prepare-klook-public-pilot.ts` конвертує observations через існуючий prepareImport. Файли записуються з flag=wx без перезапису. Це одноразова підготовка, не новий імпортер і не crawler. Повторна перевірка: `node --import tsx --test tests/klook-public-pilot.test.ts` (без мережі й без змін каталогу).

## Висновок та найкоротший наступний крок

Підписаний договір приймаємо як погоджений, повторного юридичного аудиту немає. Проте текст конкретного дозволеного способу автоматизованого доступу/використання цих фото тут не наданий; статус прав цих кандидатів не підвищується автоматично. Фактичний незалежний блокер — HTTP 403 для звичайного збирача.

Не запускаємо 900 запитів, поки перший GET заблоковано. Потрібен **дозволений Klook спосіб доступу до публічних сторінок** (наприклад, погоджений доступ для збирача/allowlist та частота, якщо Klook це підтримує). Альтернатива без партнерського кабінету: дозволений власником локальний HTML-експорт сторінок із звичайного браузера разом із фото; на його основі можна перевірити офлайн-зіставлення без мережевого обходу. Не використовувати проксі й anti-bot сервіси. Feed/API — можливий, але не єдиний варіант.

Коли дозволений доступ працюватиме: спочатку контроль 10–20 живих сторінок, звірка продукт/пакет/тип ціни/валюта/дата та фото, потім discovery лише дозволених destination/activity шляхів для Thailand/Vietnam/Indonesia/Japan/South Korea/Singapore/Malaysia. Пакети по 100–250, один послідовний запит із погодженою паузою; стоп на 401/403/429 або CAPTCHA, без автоматичних повторних спроб забороненого доступу. Мапінг у чинний ExternalImportRecord, provider+ID, існуючий checkpoint/resume, чернетки. Перед статичним snapshot — окремий review/rights/publication gate. Продукти, позначені відсутніми лише через 403, не видаляти й не вважати припиненими.

Реально отримано 12 індексованих продуктових кандидатів; автоматично завантажених живих HTML-сторінок продуктів 0; готових до публікації 0. Робочий каталог, public snapshot, .env.local, Supabase й 26 редакційних карток не змінені.
