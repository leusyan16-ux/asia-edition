# Visual foundation

Warm ivory and forest green; locally hosted Cormorant Garamond display typography; restrained sans-serif navigation. Full-width landscape photography introduces a spacious editorial collection. Country photographs lead navigation, with a clear search block and minimal chrome.

Responsive grid: three columns, two columns, then one column; mobile menu replaces desktop navigation. Country and destination pages share the hero and content system. Visible demo labels belong to every collection and detail page. Respect reduced motion and keyboard focus.

## Scope update
Public country collection covers Southeast Asia; historical non-regional country records are hidden, inheriting the existing photo-led card grid and responsive behavior. Long country names wrap inside the caption. The hero remains Vietnam and the approach image remains Bali independently of catalog ordering.

## Excursion surfaces
The ivory/forest identity continues into a denser catalog and reading-oriented tour page. Photo gallery, serif titles, compact practical details, numbered itinerary and a quiet white booking sidebar carry the hierarchy. Mobile uses a single column and a fixed link back to the parameter widget. Demonstration status and test pricing remain explicit. Native select controls, FAQ disclosures and a keyboard-dismissable gallery use accessible browser affordances.
