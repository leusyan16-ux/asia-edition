## Що зробити власнику в браузері

1. У звичайному Chrome або Edge відкрити без входу в акаунт 3–5 **сторінок конкретних продуктів**, які відкриваються звичайним способом. Наприклад, три вже відомі джерела:
   - https://www.klook.com/en-US/activity/127-gardens-by-the-bay-singapore/
   - https://www.klook.com/en-US/activity/117-universal-studios-singapore/
   - https://www.klook.com/en-US/activity/119-singapore-oceanarium/
2. Якщо сторінка заблокована або просить CAPTCHA — пропустити її. Не змінювати IP і не встановлювати засоби обходу. Скрипт не буде повторювати цей запит.
3. Установити видиму валюту **USD**, якщо цей вибір доступний. Дочекатися завантаження, прокрутити сторінку, відкрити опис, розділ Packages та один конкретний пакет. Якщо без оформлення замовлення можна вибрати дату й тип відвідувача, записати їх. Нічого не купувати й не вводити персональні дані.
4. Натиснути **Ctrl+S** → тип **«Вебсторінка повністю / Webpage, Complete»**. Зберегти як `127-en.html`, `117-en.html`, `119-en.html` у:

   `C:\Users\ya14l\Documents\ChatGPT\New project\data\manual-klook-html\input-01\`

   Папку `input-01` створити вручну. Зберегти поруч усі створені браузером папки на кшталт `127-en_files`. Не перейменовувати їх окремо від HTML. Підійде також «HTML only», але він може містити менше збереженого вмісту. **PDF, MHTML, ярлик URL або скриншот не замінюють HTML.**
5. Створити поруч `notes.txt`: для кожного файла записати повний URL, дату й час збереження, видиму валюту, назву відкритого пакета, вибрану дату/тип відвідувача та чи зазначено «від». Якщо чогось не видно — написати «не встановлено». Нотатки перевіряються вручну; вони не роблять ціну підтвердженою автоматично.
6. Повідомити в чаті: **«Зберіг файли в data/manual-klook-html/input-01»**. Файли вже будуть доступні в проєкті. Якщо браузер зберігає в Downloads, перенести HTML **разом із відповідними папками ресурсів** у вказану папку. Не надсилати cookies, HAR, токени, сторінки акаунта, замовлень або checkout.

Достатньо трьох EN-сторінок для першої перевірки витягування. Переклади й зіставлення категорій підготуємо після читання фактичного вмісту; їх не потрібно вигадувати під час збереження. До цього імпортні записи можуть утримуватися, але витягнуті поля будуть у звіті.

## Запуск розробником

З кореня проєкту:

```powershell
node --import tsx scripts/parse-klook-html.ts data/manual-klook-html/input-01 data/manual-klook-html/result-01
```

Вихідна папка має бути новою: повторний запуск не перезаписує результат. У ній:

- `observations.json`: ID/джерело, назва, опис, структурована географія/категорія, тривалість як у джерелі, пропозиції/пакети, неперевірені ціни й кандидати фото, попередження та SHA-256 HTML.
- `products.json`: лише повні кандидати у чинному `ExternalImportRecord` для CSV/JSON імпортера. Якщо бракує перекладу чи зіставлення — список може бути порожнім; це не успішний імпорт реального асортименту.
- `report.json`: прийнято/утримано, помилки по файлах, перевірка моделі й повторного імпорту; readyForPublication=0, networkRequests=0, activeCatalogModified=false.

Після редакційного уточнення можна дати третім аргументом **локальний manifest.json**, ключі — назви HTML-файлів:

```json
{
  "127-en.html": {
    "source_url": "https://www.klook.com/en-US/activity/127-gardens-by-the-bay-singapore/",
    "locale": "en",
    "country": "singapore",
    "location": { "slug": "singapore-city", "name": { "ru": "Сингапур", "en": "Singapore" } },
    "category": "parks",
    "title": { "ru": "Билет в Gardens by the Bay" },
    "description": { "ru": "Посещение садов Gardens by the Bay в Сингапуре." }
  }
}
```

Приклад містить редакційний переклад, а не підтвердження конкретного пакета. Source URL не може суперечити ID canonical/og:url. Збережені EN назва й опис залишаються першоджерелом для EN, а не підміняються manifest. Для RU-файла потрібен EN переклад. Повторне експортування того самого продукту в іншій мові в одному запуску визначається як дублікат: для цього малого тесту використовувати один основний HTML і переклади у manifest. Однойменні input-файли не перезаписувати при збереженні.

```powershell
node --import tsx scripts/parse-klook-html.ts data/manual-klook-html/input-01 data/manual-klook-html/result-02 data/manual-klook-html/manifest.json
```

## Межі та безпека

Парсер читає лише локальні UTF-8 `.html/.htm`, до 20 файлів по 16 MiB. Вхід/вихід — усередині `data/`, не `public/` чи `src/`. `data/manual-klook-html/` виключає приватні експорти й результати з Git, а весь `data/` — із Vercel upload. HTML ніколи не відкривається як сторінка нашого сайту. Ресурси, iframe, скрипти й приховані API не виконуються і не завантажуються.

Підтримуються canonical/og:url/saved-from-URL, h1/title, description/og:description, JSON-LD Product/TouristTrip/TouristAttraction/Event (з @graph/mainEntity), address/category/duration, offers/priceSpecification, OG/JSON-LD/img зображення, заголовки пакетів та видимі позначення валют. Неповний/інший DOM або стан лише всередині JavaScript не домислюється. Остаточна сумісність із реально збереженими Klook HTML **ще не перевірена**, бо файли не передані. Це обмежений екстрактор, не універсальний HTML-браузер; після першого експорту виправляємо тільки фактично потрібні селектори.

ID рекомендованих сторонніх продуктів не має замінювати ID поточної сторінки. Суперечливі джерела, challenge-сторінки, надмірні файли й дублікати утримуються. Географія/категорії, яких немає у структурованих даних, потребують явного редакційного mapping. Туреччина додатково потребує підтвердження азійської території.

Фото зберігаються як **неперевірені посилання-кандидати**. Іконки/нагороди/логотипи відсіюються за URL, але це не доводить відповідність решти фото. Локальні `*_files` посилання фіксуються, не читаються автоматично й не публікуються. Обрані фото потім перевіряються візуально та за погодженими правами.

Будь-які ціни, package identifiers, валюти, строки, назви пакетів — спостереження з HTML; importer prices/packages/images/availability залишаються порожніми. Не вгадується значення sku як package ID; діапазон 3–5 годин не перетворюється на фіксовану тривалість. Навіть структурована ціна зі строком не є автоматично перевіреною adult/child ціною: потрібні пакет, одиниця продажу, дата, умови, актуальність і редакційна перевірка. Дозвіл на публікацію не видається.

Масштабування до 900 вручну ще не підтверджене: спочатку вимірюємо якість витягування з цих 3–5 файлів та витрати часу. Це конкретна перевірка альтернативи API, а не обіцянка автоматичного збирання заблокованих сторінок.
