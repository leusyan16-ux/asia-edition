# Малайзія — обмеження до 300, 29.10.2026

Власник дозволив вибірку 300 або 350 продуктів, не весь файл. Вибрано консервативний ліміт **300 нових унікальних малайзійських продуктів** у порядку джерела, після дедуплікації та перевірки географії.

## Облік

- Таблиця: 589 рядків. Три посилання на редакційні статті не є екскурсіями; лишилось 586 activity-рядків.
- 528 унікальних activity ID, 58 повторів усередині activity-рядків.
- Два ID вже є в локальному каталозі — не дублювали й не змінювали.
- Серед нових кандидатів два належать Індонезії/Сінгапуру, два відкладено через суперечливі назву/URL або згадку напрямку, що потребує географічної перевірки.
- 522 придатні нові малайзійські ID; **вибрано 300**, решту **222 не імпортовано**. Оригінальні файли збережено.
- Додано 300 чернеток. Локальний GetYourGuide-каталог тепер має 1761 продукт, публічний snapshot не змінений (849 карток).
- Перенесено 224 однозначні цінові спостереження USD, 227 рейтингів, наявні характеристики. Акційні/пакетні суми без однозначного змісту не обиралися довільно; `preflight.json` містить випадки для перевірки.
- Для 300 нових чернеток написано короткі редакційні RU/EN summaries за наданими назвами/напрямками, без вигаданих цін, рейтингів, доступності чи включених послуг.

## Фото та перевірки

Фото є для всіх 300 вибраних продуктів. Це 293 унікальні URL; усі завантажилися HTTP 200 та успішно декодувалися sharp, 0 помилок (`qa/malaysia-photo-checks.json`). Повної змістової візуальної перевірки всіх фото не заявляємо.

96/96 тестів пройдено (`qa/malaysia-tests.log`). Перевірки TypeScript, ESLint, production build: `qa/malaysia-{ts,lint,build}.log`. Локальна перевірка 600 рендерів RU/EN, 300 skip при повторному імпорті, незмінність попередніх 1461 продукту та 26 редакційних карток: `qa/malaysia-final-verification.log`.

Використано існуючі парсер/адаптер, prepareImport/commitExternalImport/saveLocalBatch; лише розширено малайзійські place slugs та розпізнавання місцевих Little India/Chinatown як кварталів. Явні маршрути до India/China/РФ залишаються заблокованими. Повних маршрутів операторів ця перевірка не підтверджує.

Приватні матеріали: `data/getyourguide-malaysia/source-{table,listing}.txt`, `source-products.json` (рівно 300 відібраних записів), `preflight.json`, `import-final/{products,report,admin-links}.json`, `final-report.json`, `review-input.json`, `publication-worksheet.json`. Перед змінами створено резервні копії. Worksheet має approval=false, жодних дозволів на публікацію не додає.

Нову партію не публікували. Не змінювали Supabase, `.env.local`, бронювання, оплату, Vercel, попередні 1461 продукт та 26 редакційних карток. Сінгапур/Індонезія також лишаються чернетками до окремого погодження.
