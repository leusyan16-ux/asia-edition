## Фото

Проблема: галереї розтягували мініатюри 540×360, призначені для списку. Новий спільний TourPhoto запитує той самий дозволений asset у розмірах до 800px для картки, 1600px для сторінки й 2000px для lightbox. CDN fit=scale-down зберігає пропорції та не збільшує фото понад нативну роздільність. При помилці нового розміру є fallback до наданого URL, потім — нейтральне оформлення.

Для прикладу 1001869 отримано й перевірено справжній кадр 1280×960 замість 540×360. Вищу деталізацію, якої немає в оригіналі, не вигадували. Всі 2268 унікальних URL високоякісних версій повернули HTTP 200/image. Нових фотографій не збирали й не генерували. 2302 картки мають надані фото; для 17 джерела не містять доступного фото.

## Деталі

- Спільний інформаційний шаблон для всіх 2319 карток: огляд, факти, головні враження, підготовка, FAQ, пов’язані екскурсії та посилання на чинну форму уточнення.
- 1388 карток мають тривалість із наданого тексту, включно з діапазонами й днями без перетворення їх у вигадане середнє.
- 582 мають вказаний формат групи; 800 — згадку можливості трансфера. Це не обіцянка включення трансфера у кожен пакет.
- Для 49 карток підготовлено індивідуальні редакційні абзаци за наданими назвами, характеристиками й описами. Виявлено 48 однозначно зіставлених довгих текстів; окремо уточнено приклад 1001869 з наданими 4 годинами й базовим/безалкогольним варіантами.
- Інші описи спираються на назви, категорії та наявні характеристики; практичні блоки не видаються за підтверджений маршрут постачальника.
- Збережено існуючу триденну програму Тимор-Лешті. Не вигадували адреси, погодинні маршрути, включені послуги, ціни, рейтинги, наявність або безкоштовне скасування.

Новий scope штатного інформаційного схвалення `titles-source-details-images` дозволяє лише інформаційні факти. Digest зв’язує їх з усією публічною карткою. Старі scopes не можуть додати facts непомітно. Комерційні prices/availability/normal duration залишаються порожніми/null; джерельні чернетки не публікувались.
